# FastCull Read docs/PRD.md before any task. It is the source of truth. ## Non-negotiable constraints - Prime directive: the app must feel instant. See PRD section 0. - The UI thread does no I/O, no decoding, no DB writes, no metadata parsing. Ever. - Current phase: v0.1 only. Do not implement zoom, HUD, undo, or batch export yet. - Every decode job takes a CancellationToken. - LibRaw is primary for RAW formats. WIC is primary for everything else and fallback for RAW. - Target framework is .NET 9.0, WinUI 3 (Windows App SDK). ## Working rules - One task at a time. Build must pass (dotnet build) before moving to the next. - After each task: confirm the build succeeds, then commit with a clear message. - Do not add NuGet packages not listed in PRD section 5.2 without asking first. - Do not refactor files outside the current task's scope.
